# boss-agent

A small command-line task tracker, used by a team of four as the vehicle for the
collaborative-workflow trial in the group assessment. The product scope is deliberately
narrow: one requirement can be carried from a tracked backlog item through implementation,
test and review inside a short iteration.

## Status

Iteration 1 — repository scaffold in place. Setup, usage and test instructions are added
together with the first vertical slice.
