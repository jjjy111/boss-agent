## Why

Every task looked equally urgent, so the list stopped being a decision aid. REQ-001 makes
a due date part of a task and adds an overdue view that answers "what am I already late
on?" without the user reading the whole list.

## What changed

| Layer | Change | File |
| --- | --- | --- |
| Domain | optional `due: date` on `Task`; `is_overdue(today=None)` with an injectable clock | `boss_agent/models.py` |
| Persistence | `due` serialised as an ISO string (or `null`); `TaskStore.add(title, due=None)` | `boss_agent/store.py` |
| CLI | `add --due YYYY-MM-DD`, `list --overdue`, `(due YYYY-MM-DD)` in the list output, `nothing overdue` for an empty view | `boss_agent/cli.py` |
| Tests | five acceptance tests mapped onto AC1–AC5 | `tests/test_due_dates.py` |

Exit codes are unchanged: `0` on success, `2` for invalid input, with the message on
stderr and no traceback.
