## 验收口径

1. 演示脚本可在空数据库上一次生成完整样例，重复运行时不得覆盖已有数据库。
2. 岗位接口返回岗位、城市、薪资、JD、匹配分和归档状态等字段。
3. 每日岗位按批次日期分组，样例覆盖杭州、宁波、上海三座城市。
4. 岗位可标记已读、归档，并可恢复为有效岗位。
5. 本地扩展握手必须校验本机 token；未授权请求返回 `401`。
6. 采集任务按杭州、宁波、上海的顺序下发。
7. 不完整 JD、运营岗、非目标岗位、明确要求硕士及以上或两年以上经验的岗位应被过滤。
8. 只有完整采集才允许归档本次未出现的旧岗位；部分采集和失败采集不得误归档。
9. 首页静态资源可访问，`frontend/app.js` 通过语法检查。

## 测试数据

空数据库运行 `python scripts/seed_demo_data.py` 后，实际写入：

- 6 个岗位：3 个当日岗位、3 个前一日岗位。
- 城市分布：杭州 3 个、宁波 1 个、上海 2 个。
- 岗位状态：5 个有效岗位、1 个已归档岗位。
- 2 份虚构通用简历、1 份定制草稿、1 条成功的采集记录。

## 复现方式

```bash
python scripts/seed_demo_data.py
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

打开 `http://127.0.0.1:8000/`，检查每日岗位、持续岗位和岗位归档三个视图，并切换样例批次日期。

## 范围与残余风险

- 本轮使用虚构数据验证接口和采集规则，未使用真实 BOSS 账号执行实网采集。
- BOSS 登录、安全验证和页面结构会受账号及线上页面变化影响，首次安装扩展后仍需人工完成一次冒烟采集。
- 实网冒烟不通过时不得归档旧岗位；应先修复扩展或调整页面选择器，再重新执行完整采集。

## 结论

第 1 轮演示数据、岗位接口、扩展握手与任务下发、岗位归档/恢复和采集过滤规则通过验收。实网 BOSS 冒烟保留为人工环境检查项。
